# PlaceTimeShifts
Code used for "Speed-dependent place- and time-field shifts do not require explicit temporal coding"


-Fig1.py generates figure 1.

-compute_field_centres.m and Fig2.m generate figure 2.

-gen_train_set.py can be used to generate a training dataset for both space and space+time RNNs.

-model.py contains the RNN class

-train_model.py can be used to train both a space or space+time model

-gen_test_set.py and gen_test_structured.py generate the dataset to evaluate the model and generate the figures

-Functions.py includes functions used for model analysis.

-Remaining files are used to generate all figures.
